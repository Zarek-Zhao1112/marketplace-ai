# SKU生命周期与滞销品处置

## SKU生命周期阶段

| 阶段 | 定义 | 运营策略 |
|------|------|----------|
| 新品期 | 上架 < 30天 | 给予观察期，优化listing，不必急于下架 |
| 成长期 | 销量逐月上升 | 加大推广，补充库存 |
| 成熟期 | 销量稳定，是核心SKU | 维持运营，监控RMA和竞品 |
| 衰退期 | 销量连续下降，或零销售 > 30天 | 启动滞销处置流程 |

## 零销售高库存 SKU 处置决策树

```
零销售高库存 SKU
├── 是否新品（<30天）？
│   ├── 是 → 评估保留，30天复查
│   └── 否 ↓
├── 是否长期滞销（>90天零销）？
│   ├── 是 → 立即下架
│   └── 否 ↓
├── 供应商是否接受退货？
│   ├── 是 → 退货供应商
│   └── 否 ↓
├── 是否有热销 SKU 可捆绑？
│   ├── 是 → 捆绑销售
│   └── 否 ↓
├── 是否多站点卖家？
│   ├── 是 → 多站点调拨 或 报活动
│   └── 否 ↓
├── 当前售价 vs 成本价，降价空间 > 20%？
│   ├── 是 → 降价清库存 或 报活动
│   └── 否 ↓
├── Listing 质量是否明显低于竞品？
│   ├── 是 → 换链接重上
│   └── 否 → 报活动清库存
```

## 八种处置选项详解

### A. 立即下架
- **适用**：长期滞销（>90天零销）、无战略价值、供应商不退货
- **动作**：Deactivate listing，停止占用曝光位
- **时间**：立即

### B. 降价清库存
- **适用**：有成本价、可承受降价、库存量可控
- **动作**：降价 10-30%，观察 2 周
- **时间**：2-4周

### C. 报活动清库存
- **适用**：库存量大、价格有竞争力、愿意承担活动折扣
- **动作**：报名 Spotlight Sale / Deal Portal / Email 促销
- **时间**：1-4周

### D. 换链接重上
- **适用**：当前 listing 质量差（图片/描述/A+ 内容），但产品本身有需求
- **动作**：关闭旧 listing，创建新 listing
- **时间**：2-4周

### E. 捆绑销售
- **适用**：有明确的热销 SKU 可搭配
- **动作**：创建 Bundle SKU，绑定销售
- **时间**：2-4周

### F. 退货供应商
- **适用**：供应商接受退货、退货成本 < 库存持有成本
- **动作**：发起退货流程，退回供应商
- **时间**：2-6周

### G. 多站点调拨
- **适用**：多站点卖家、其他站点有同类需求
- **动作**：从 B2C 调拨到 CA/B2B
- **时间**：2-4周

### H. 评估保留
- **适用**：新品（<30天）、季节性产品、战略级 SKU
- **动作**：保持 Active，月度复查
- **时间**：持续

## 优先级排序

当多个选项同时适用时，按以下优先级选择：
1. F. 退货供应商（最优，完全止损）
2. E. 捆绑销售（利用现有流量，成本低）
3. C. 报活动清库存（批量出货，但需承担折扣）
4. G. 多站点调拨（跨站点消化，需协调）
5. B. 降价清库存（快速但牺牲利润）
6. D. 换链接重上（有不确定性，需评估 listing 问题）
7. A. 立即下架（保底选项）
8. H. 评估保留（仅限新品/战略品）

## 操作注意事项

- 下架前检查是否有未完成的订单需要履约
- 报活动前确认库存充足，避免超卖
- 退货供应商前确认退货政策和运费承担方
- 换链接重上时保留旧 listing 的 review 数据（如有）
- 捆绑销售时注意 Bundle 定价要低于单独购买总和
