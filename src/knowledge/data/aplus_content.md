# A+页面（A+ Content）

A+ Content 是一种功能，卖家可以快速为其商品页面构建增强内容，包括丰富的图片、文字和图表，为客户提供最佳的购物体验。

**使用A+ Content的商品页面显示出更高的页面浏览量和转化率。**

## 创建A+内容

### 步骤
1. 登录Seller Portal → 商品 → A+ Content
2. 点击"创建 A+ 内容"按钮
3. 同意A+ Content Terms & Conditions（首次使用）
4. 分配Content Name（内部跟踪用）
5. 选择要应用A+ Content的SKU
6. 添加模块（最少3个，最多5个）
7. 提交审核

### 内容状态
- **草稿**：已保存，未发布
- **已提交**：正在审核
- **已发布**：网站上实时显示
- **已拒绝**：未通过审批

## A+内容模块

### 可用模块类型

| 模块名称 | 功能 | 布局 |
|----------|------|------|
| 标准视频 | 基础视频 | 视频播放器 |
| 带文本的标准图像页眉/页脚 | Top Banner和文本 | 横幅+文字 |
| 标准公司标志 | 横幅 | Logo展示 |
| 标准单左图 | 左对齐图片，标题&副标题 | 图片左+文字右 |
| 标准单右图像 | 右对齐图像，标题和副标题 | 图片右+文字左 |
| 标准多图文 | 图像位于文本上方，标题 | 图片上+文字下 |
| 标准四图/文本象限 | 四张图片和文字，标题 | 四宫格 |
| 标准图像和轻文本叠加 | 图片上方的轻文字小框 | 图片+覆盖文字 |
| 标准图像与深色文字覆盖 | 图像上方的深色文字小框 | 图片+深色文字 |
| 标准多图模块 | 多图轮播，标题 | 轮播图 |
| 标准单图&亮点 | 图像、文本和项目符号 | 图片+要点列表 |
| 标准单图像与侧边栏 | 图片、文本和勾选标记 | 图片+侧边栏 |
| 标准单图像与规格详情 | 图片、文本和规格列表 | 图片+规格表 |
| 标准技术规格 | 文本规格网格 | 规格表格 |
| 标准比较表 | 带图片和规格的比较表 | 对比表格 |
| 标准描述文本 | 仅文本 | 纯文字 |
| 标准文本 | 带标题和副标题的文本 | 标题+正文 |

### 模块使用建议
1. **讲述产品故事**：回答客户可能的问题
2. **展示最佳特性**：突出产品优势
3. **展示用途**：让客户了解使用场景
4. **至少3个模块**：丰富内容展示

## 高级功能

### 视频支持
- 可以在A+ Content中放置YouTube视频
- 增强产品展示效果

### 规格表
- Multi-Image模块支持插入规格表
- 尺寸限制：1×1 到 4×16
- 可使用Excel表格

### 颜色主题
- 可以选择/自定义颜色主题
- 匹配品牌风格

### 预览功能
- 支持移动端和桌面端预览
- 确保内容显示正确

## 审核流程

### 审核时间
- 大多数请求在1个工作日内发布

### 审核标准
- 内容符合Newegg内容政策
- 图片清晰，文字准确
- 无违规内容

### 被拒绝怎么办
- 查看拒绝原因
- 修改后重新提交
- 联系内容团队：mktp.content@newegg.com

## 最佳实践

1. **图片质量**：使用高分辨率图片
2. **文字简洁**：避免大段文字，使用要点列表
3. **品牌一致**：保持品牌视觉风格一致
4. **移动端优化**：确保在手机上显示正常
5. **定期更新**：根据销售数据优化内容
