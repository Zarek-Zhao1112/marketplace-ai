# 促销活动

## 活动类型
1. Lightning Deal（闪购）
2. Spotlight Sale（聚光灯促销）
3. Email促销
4. WMT Flash Deal
5. BBY DOTD

## 提交流程

### 步骤
1. 登录Seller Portal → 营销 → 活动
2. 查看符合条件的活动
3. 点击'注册'添加商品
4. 填写活动信息（价格、库存等）
5. 提交审核

### 注意事项
- 提前2周提报
- 价格要有竞争力
- 库存要充足
- 注意活动时间
