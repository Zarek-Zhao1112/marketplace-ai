# SBN管理

## 自动化多渠道订单拣配
- **说明**: 自动处理SBN的多渠道订单
- **功能**: 自动拣货、包装、发货

## 新蛋仓库货件列表
- **说明**: 管理发送到Newegg仓库的货件

### 步骤
1. 创建货件计划
2. 打印货件标签
3. 发送货件到仓库
4. 查看入仓状态

## 库存警报
- **说明**: 当SBN库存低于阈值或缺货时发送警报
- **设置**: 可设置最低库存阈值
