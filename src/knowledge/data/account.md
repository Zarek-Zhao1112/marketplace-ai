# 账户管理

访问一般账户信息：会员资格、配送、税务、假期、数据接口和业务信息。

## 账号设置

### 更新业务信息
- 访问：Seller Portal → 账户 → 账号设置 → 更新业务信息
- 可更新：公司名称、地址、联系方式等

### 更新财务信息
- 访问：Seller Portal → 账户 → 账号设置 → 更新财务信息
- 可更新：银行账户、收款方式等

### 添加/更新地址
- 访问：Seller Portal → 账户 → 账号设置 → 添加/更新地址
- 支持：多个配送中心地址

### 添加/更新卖家通知管理
- 访问：Seller Portal → 账户 → 账号设置 → 添加/更新卖家通知管理
- 功能：设置邮件通知接收人

### 登录设置 & 密码重置
- 访问：Seller Portal → 账户 → 账号设置 → 登录设置 & 密码重置
- 功能：修改密码、更新登录邮箱

### 添加子账户
- 访问：Seller Portal → 账户 → 账号设置 → 添加子账户
- 功能：为团队成员创建子账户

### 管理用户权限
- 访问：Seller Portal → 账户 → 账号设置 → 管理用户权限
- 功能：设置不同用户的访问权限

### 停用账号
- 访问：Seller Portal → 账户 → 账号设置 → 停用账号
- 功能：停用不再使用的子账户

### 商品类目参考列表
- 访问：Seller Portal → 账户 → 账号设置 → 商品类目参考列表
- 功能：查看所有可用的商品类目

### 更新信用卡信息
- 访问：Seller Portal → 账户 → 账号设置 → 更新信用卡信息
- 功能：更新付款信用卡

### 更新所有权信息
- 访问：Seller Portal → 账户 → 账号设置 → 更新所有权信息
- 功能：更新公司所有权信息

## 配送设置

### 添加/更新配送中心
- 访问：Seller Portal → 账户 → 配送设置 → 添加/更新配送中心
- 功能：设置发货仓库地址

### 设置配送中心优先级
- 访问：Seller Portal → 账户 → 配送设置 → 设置配送中心优先级
- 功能：多个配送中心时设置优先级

### 更新售后政策
- 访问：Seller Portal → 账户 → 配送设置 → 更新售后政策
- 功能：设置退货政策、退款规则

### 更新库存召回地址
- 访问：Seller Portal → 账户 → 配送设置 → 更新库存召回地址
- 功能：设置退货商品返回地址

### 更新运费模式和费率
- 访问：Seller Portal → 账户 → 配送设置 → 更新运费模式和费率
- 功能：设置运费计算方式和费率

### 设置新蛋国际配送服务
- 访问：Seller Portal → 账户 → 配送设置 → 设置新蛋国际配送服务
- 功能：启用国际配送（NISP）

### 新蛋国际配送服务NISP
- 说明：Newegg International Shipping Program
- 功能：让卖家的商品可以销售到全球市场

### 删除新蛋国际配送服务
- 访问：Seller Portal → 账户 → 配送设置 → 删除新蛋国际配送服务
- 功能：停用国际配送

### 更新税收设置(CAN)
- 访问：Seller Portal → 账户 → 配送设置 → 更新税收设置(CAN)
- 功能：设置加拿大站点税收

### 启用/停用新蛋售后服务
- 访问：Seller Portal → 账户 → 配送设置 → 启用/停用新蛋售后服务
- 功能：让Newegg处理退货售后

## 会员设置

### 会员更新
- 访问：Seller Portal → 账户 → 会员设置 → 会员更新
- 功能：升级或降级会员等级

### 会员等级
- **Basic（基础会员）**：新卖家默认
- **Elite（精英会员）**：达到一定销售额自动升级
- **Premium（高级会员）**：邀请制

### 会员权益
- 佣金优惠
- 促销活动优先参与
- 专属客服支持
- 高级报表功能

## 数据接口设置

### API访问授权 – 请求API凭证
- 访问：Seller Portal → 账户 → 数据接口设置 → API访问授权
- 功能：获取API密钥，用于ERP系统对接

### 国际站价格同步
- 访问：Seller Portal → 账户 → 数据接口设置 → 国际站价格同步
- 功能：自动同步B2C/CA/B2B站点价格

## 假期设置

### 卖家账户假期设置
- 访问：Seller Portal → 账户 → 假期设置 → 卖家账户假期设置
- 功能：设置店铺休假期间

### 编辑假期日期
- 访问：Seller Portal → 账户 → 假期设置 → 编辑假期日期
- 功能：修改休假时间段

### 取消店铺休假
- 访问：Seller Portal → 账户 → 假期设置 → 取消店铺休假
- 功能：提前结束休假

### 假期注意事项
- 休假期间不会收到新订单
- 假期设置会影响店铺评分
- 建议提前设置，避免影响运营
