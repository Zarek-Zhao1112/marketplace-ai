# Newegg Seller Academy 知识库迁移总结

> 迁移日期：2026-07-24
> 迁移内容：从Python硬编码格式迁移到Markdown格式

---

## 一、迁移背景

### 为什么迁移？

| 问题 | 说明 |
|------|------|
| **可读性差** | Python代码文件只有懂代码的人能看懂 |
| **维护困难** | 修改内容需要懂Python语法 |
| **无法分享** | 不能直接分享给同事或用Obsidian打开 |
| **版本控制不直观** | Git diff显示的是代码变化，不是内容变化 |

### 迁移目标

- ✅ 用普通Markdown文件存储知识库内容
- ✅ 保持向后兼容，现有代码无需修改
- ✅ 支持未来用Obsidian管理
- ✅ 更易维护和分享

## 四、使用方式

### 向后兼容

现有代码无需任何修改：

```python
from src.knowledge import get_knowledge, search_knowledge

# 按分类获取
platform_data = get_knowledge("platform")

# 搜索
results = search_knowledge("RMA")
```

### 新增模块

```python
# 获取账户管理知识
account_data = get_knowledge("account")

# 获取价格保护知识
pricing_data = get_knowledge("pricing")
```

### 直接编辑MD文件

想修改知识库内容，直接编辑 `src/knowledge/data/` 下的MD文件即可：

```bash
# 用任何文本编辑器打开
code src/knowledge/data/platform.md

# 或者用记事本
notepad src/knowledge/data/platform.md
```
