---

## 一、AI调用总览

| 风险等级 | 说明 |
|----------|------|
| 🟢 无AI | 纯本地计算，数据不出本机 |
| 🟡 有AI | 调用外部AI服务（豆包API） |
| 🔴 敏感AI | AI处理的数据含销售/财务/聊天记录等敏感信息 |

## 三、敏感数据流向汇总

### 发送到外部AI的数据类型

| 数据类型 | 包含敏感信息 | 涉及页面 |
|----------|--------------|----------|
| 企业微信聊天记录 | 可能含订单号、金额、卖家信息 | 问题管理 |
| 卖家消息原文 | 可能含具体问题、订单详情 | 问题管理 |
| 历史对话对 | 运营回复模式、处理方案 | 问题管理 |
| 品牌官网内容 | 公开信息，无财务数据 | 品牌线索、招商管理 |

### 未发送到AI的敏感数据（本地存储）

| 数据类型 | 存储位置 | 涉及页面 |
|----------|----------|----------|
| 卖家GMV、毛利、RMA% | `data/seller_history/` | 卖家分析 |
| SKU销售明细 | `data/sku_analysis/` | 卖家分析 |
| 问题记录（含卖家名称） | `data/issues.xlsx` | 问题管理 |
| 联系人邮箱、职位 | `data/contacts.xlsx` | 商家通讯录 |
| 品牌跟进记录 | `data/brands.xlsx` | 品牌线索 |

## 四、隐私合规建议

### 如需禁止销售数据发送给AI

**卖家分析页面已满足要求** - 无AI调用，所有数据本地处理。

**问题管理页面需注意：**
- 聊天记录提取功能会将聊天内容发送到豆包API
- 建议：手动录入问题，或对聊天记录脱敏后再使用AI提取

### 如需完全禁用AI功能

可在 `.env` 文件中添加开关：

```env
ENABLE_AI_ANALYSIS=false
```

然后在代码中检查此环境变量，禁用所有AI调用。
