## 五、话术使用原则

| 原则 | 说明 |
|------|------|
| 先建立关系 | 不要一上来就推销，先聊产品 |
| 给对方理由 | 加微信是为了发资料，不是为了推销 |
| 展示专业度 | 提到你分析过80个卖家，增加可信度 |
| 保持耐心 | 对方需要时间考虑，不要催太急 |
| 定制话术 | 根据店铺特点调整，不要群发 |
| 记录跟进 | 每次沟通都要记录，方便后续跟进 |
