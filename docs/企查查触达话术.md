# 企查查/天眼查触达话术

> 从企查查找到公司后，打电话/加微信的话术

---

## 一、电话话术

### 场景1：直接打电话（推荐）

**开场**：
```
喂，你好，请问是[公司名]吗？我是Newegg北美电商平台的，想了解一下你们有没有兴趣做北美市场。
```

**对方问"Newegg是什么"**：
```
Newegg是北美第二大电商平台，纳斯达克上市公司，4000多万用户，主要做3C、耳机、智能家居这些品类。

我们想找一些有货源优势的供应商合作，你们在耳机/音频领域做得挺好的，想了解一下有没有兴趣。
```

**对方问"具体怎么做"**：
```
入驻很简单，准备营业执照、身份证、收款账号这些就行。我们有专属运营团队支持，当天就能开店。

新卖家前90天佣金只要6%，比其他平台低。
```

**对方说"考虑一下"**：
```
好的，不着急。我加你微信，把详细资料发给你，有空看看。你微信号多少？
```

**对方说"没兴趣"**：
```
好的，理解。如果以后有兴趣，随时联系我。祝生意兴隆！
```

**对方说"太忙了"**：
```
理解，生意忙是好事。我加你微信，资料发给你，有空看看。不着急。
```

---

### 场景2：电话打不通/没人接

**发短信**：
```
你好，我是Newegg北美电商平台的Zarek。看到你们公司做[品类]做得挺好的，想了解一下有没有兴趣做北美市场。

新卖家前90天佣金只要6%，我们有专属运营团队支持。

方便加个微信聊聊吗？我的微信是[你的微信号]。
```

---

### 场景3：打到前台/客服

**话术**：
```
你好，请问你们公司负责[耳机/音频]业务的负责人在吗？我是Newegg北美电商平台的，想聊一下北美市场合作。
```

**如果前台说"负责人不在"**：
```
好的，方便留个负责人的手机号或微信吗？我加他发些资料。
```

## 二、加微信话术

### 场景1：电话聊过后加

**验证信息**：
```
你好，我是Newegg的Zarek，刚才电话聊过，想发些北美市场的资料给你看看。
```

### 场景2：直接加（没聊过）

**验证信息**：
```
你好，我是Newegg北美电商平台的Zarek，看到你们公司做[品类]做得挺好的，想聊聊北美市场合作。
```

### 场景3：通过前台/客服加

**验证信息**：
```
你好，我是Newegg的Zarek，之前打过电话，想发些资料给负责人看看。
```

## 三、微信沟通话术

### 场景1：发送资料

```
你好，这是我们Newegg平台的资料，你看看。

主要信息：
1. 北美第二大电商平台，4000万+用户
2. 新卖家前90天佣金只要6%
3. 有官方ERP工具支持
4. 专属运营团队全程支持

你们在[品类]做得挺好的，有货源优势，在Newegg上应该很有竞争力。

有什么问题随时问我。
```

### 场景2：对方看完资料

```
资料看完了吗？有什么问题吗？如果感兴趣，我帮你对接运营团队，当天就能开店。
```

### 场景3：对方表示感兴趣

```
太好了！我帮你对接运营团队。你需要准备营业执照、身份证、收款账号这些，准备好就能当天开店。
```

### 场景4：跟进（3天后）

```
你好，资料看了吗？有什么问题吗？如果感兴趣，随时可以对接运营团队。
```

### 场景5：跟进（7天后）

```
你好，之前聊的事情考虑得怎么样了？我们随时可以对接。
```

## 四、常见问题应对

| 问题 | 回答 |
|------|------|
| Newegg是什么 | 北美第二大电商平台，纳斯达克上市公司，4000万+用户 |
| 和亚马逊有什么区别 | 用户更精准，佣金更低（90天6%），竞争更小 |
| 入驻需要什么 | 营业执照、身份证、外币收款账号、W8表格、外币信用卡 |
| 需要多少钱 | 入驻免费，佣金6-15%，SellingPilot 99元/月可选 |
| 做什么品类好 | 耳机、智能家居、小家电都是蓝海 |
| 有官方支持吗 | 有，SellingPilot官方ERP + 专属运营团队 |
| 物流怎么解决 | SBN新蛋发货，排名更高，24/7客服 |
| 你是谁 | 我是Newegg的BD，负责帮优质供应商对接北美市场 |

## 六、话术使用原则

| 原则 | 说明 |
|------|------|
| 先聊产品再聊合作 | 不要一上来就推销 |
| 语气像真人聊天 | 不要太正式 |
| 展示专业度 | 提到Newegg平台数据 |
| 保持耐心 | 对方需要时间考虑 |
| 记录跟进 | 每次沟通都要记录 |
