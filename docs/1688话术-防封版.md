# 1688话术（防封版）

> 每条消息都不一样，避免被判定为营销号

---

## 核心原则

1. **每条消息改几个字**：不要完全一样
2. **语气像真人聊天**：不要太正式
3. **先聊产品再聊合作**：不要一上来就推销
4. **每天控制数量**：最多5-8条

## 回复话术（根据对方回复）

### 对方问"什么平台"
```
Newegg，北美第二大电商平台，纳斯达克上市公司。主要做3C、智能家居、小家电这些品类，用户购买力挺强的。
```

### 对方问"具体怎么做"
```
入驻很简单，准备营业执照、身份证、收款账号这些就行。我们有专属运营团队支持，当天就能开店。
```

### 对方问"有什么优势"
```
新卖家前90天佣金只要6%，比其他平台低。而且我们用户很精准，客单价$200+，你们有货源优势应该很有竞争力。
```

### 对方说"考虑一下"
```
好的，不着急。我加你微信，把详细资料发给你，有空看看。有什么问题随时问我。
```

### 对方说"没做过跨境"
```
没关系，我们有中国区专属运营团队，全程支持。入驻流程很简单，准备营业执照、身份证这些就行。
```

### 对方说"太忙了"
```
理解，生意忙是好事。我加你微信，资料发给你，有空看看。不着急。
```

### 对方问"你是谁"
```
我是Newegg的BD，负责帮优质供应商对接北美市场。你们产品挺好的，想了解一下有没有兴趣。
```

### 对方问"要多少钱"
```
入驻免费，佣金6-15%看品类。我们有官方ERP工具，99块一个月，不强制用。
```

```

```

### 对方没回复（7天后）

## 注意事项

| 要做 | 不要做 |
|------|--------|
| 每条消息改几个字 | 发完全一样的消息 |
| 每天控制5-8条 | 一天发几十条 |
| 先聊产品再聊合作 | 一上来就推销 |
| 语气像真人聊天 | 太正式像机器人 |
| 回复后再发下一条 | 连续发好几条 |
| 记录每天发了哪些 | 不记录重复发 |
